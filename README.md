# 片葉 — 古典籍IIIFリーダー

**見開きで撮影された古典籍を、タブレットで片面ずつ読むためのWebビューアです。**

IIIF ManifestのURLを入力すると画像を読み込み、綴じ目の位置を推定して、右面・左面を順に表示します。画像の拡大表示には[OpenSeadragon](https://openseadragon.github.io/)を使用しています。

現在は試作版です。自動検出で位置が合わない場合は、手動で調整してください。

## 主な機能

- IIIF Manifest URLからの画像読み込み
- 綴じ目の自動推定
- 片面表示／見開き表示の切り替え
- 右面→左面、左面→右面の読み順切り替え
- 綴じ目の上端・下端の手動調整
- 表紙など、画像ごとの「分割しない」設定
- ピンチ操作による拡大、ボタン・キーボードによるページ送り
- 画像番号の選択による移動
- 読書位置・分割位置・読み順のブラウザ内保存

## 片面表示の仕組み

解析用の縮小画像から、中央付近にある暗い縦線の候補を探して綴じ目を推定します。OCRや学習済みモデルは使用していません。

綴じ目が斜めになっている場合も、表示領域は長方形です。綴じ目の上端と下端の間にある縦の帯を、左右両面に重複して表示します。

たとえば、上端が画像幅の48%、下端が52%の位置にある場合は、次の範囲を表示します。

| 表示する面 | 横方向の表示範囲 |
| --- | --- |
| 右面 | 48%〜100% |
| 左面 | 0%〜52% |
| 両面に重複する範囲 | 48%〜52% |

この方式により、傾きの誤検出によって綴じ目付近の文字が斜めに切り落とされることを避けます。ただし、綴じ目の位置自体を大きく誤認した場合は、手動調整が必要です。

元画像は変更しません。ビューア内で表示範囲を切り替えます。

## 使い方

1. 「IIIF Manifest URL」に資料のManifest URLを入力します。
2. 「開く」を押します。
3. 「次へ」「前へ」で片面ずつ移動します。
4. 必要に応じて拡大したり、見開き表示へ切り替えたりします。

「試し読み」では、動作確認用の模擬画像を表示できます。実際の古典籍画像ではありません。

### 綴じ目を調整する

1. 「綴じ目を調整」を押します。
2. 「上端」「下端」のスライダーを動かすか、プレビュー上の線の上側・下側をドラッグします。
3. 色付きの帯で、左右両面に重複する範囲を確認します。
4. もう一度「綴じ目を調整」を押すと、調整画面が閉じます。

「再検出」で現在の画像の自動推定をやり直せます。手動調整した位置も再推定結果に置き換わります。

表紙や単ページ画像は「この画像は分割しない」を選択してください。縦長の画像は初回読み込み時に分割しない設定となる場合があります。

### 操作一覧

| 操作 | 内容 |
| --- | --- |
| 次へ／前へ | 現在の読み順に沿って移動 |
| 画像番号の選択 | 指定した画像へ移動 |
| 見開きにする／片面にする | 表示モードを切り替え |
| 右面→左面／左面→右面 | 画像内の読み順を切り替え |
| 全体を収める | 現在の面または見開きを表示領域に収める |
| ピンチ操作 | 拡大・縮小 |
| 左右の矢印キー | 読み順に応じて移動 |
| 左右スワイプ | 標準倍率付近でページ送り |

タッチ操作の挙動は、ブラウザや端末によって異なる場合があります。スワイプが反応しない場合は、ページ送りボタンをご利用ください。

## 対応する資料

IIIF Presentation API v2・v3のうち、各Canvasに画像1枚を配置した基本的なManifestを対象にしています。

- IIIF Image APIの画像サービス、または直接参照された画像を読み込みます。
- 複数画像の合成、画像の選択肢、動画などを含む複雑なManifestの完全な解釈には対応していません。
- 配信元がCORSに対応している必要があります。非対応サイトを中継するプロキシ機能はありません。
- HTTPSで公開する場合は、Manifestや画像の配信元もHTTPSのURLをご利用ください。
- 画像サービスの縮小画像やタイルの配信仕様によっては、読み込めない場合があります。

## 保存する情報と通信

画像とManifestは、利用者のブラウザが各配信元から直接取得します。ビューアを置いたGitHub Pagesに資料画像を保存する仕組みではありません。

綴じ目の解析はブラウザ内で行います。

読書位置、分割位置、分割の有無、読み順は、Manifest URLごとにブラウザの `localStorage` に保存します。同じURLのManifestを再び開くと復元します。

- 別の利用者とは共有されません。
- 別の端末・ブラウザとは同期されません。
- サイトのURLが変わると、以前の保存内容は引き継がれません。
- ブラウザのサイトデータを削除すると、保存内容も失われます。
- プライベートブラウズや保存制限のある環境では、保存できない場合があります。

## 現在の制限と検証状況

自動検出は、中央付近の暗い線の候補を用いる簡易的な推定です。罫線・挿絵・影などを綴じ目と誤認する場合があります。また、推定に使う中央付近の範囲から綴じ目が外れている画像では、正しく検出できない可能性があります。

湾曲した綴じ目の追跡、紙面の歪み補正、OCR、分割画像の書き出しには対応していません。

## 読み込めないとき

- 書誌ページや通常の閲覧ページではなく、IIIF ManifestのURLを入力しているか確認してください。
- Manifestと画像の配信元がCORSに対応しているか確認してください。
- 配信元の停止やURL変更、HTTPS／HTTPの混在がないか確認してください。
- 対応範囲外のManifest構造の場合もあります。

表示される読み込みエラーだけでは、原因をCORSに特定できない場合があります。
